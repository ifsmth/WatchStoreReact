# Підключення фронтенду до API

Збірка фронтенду налаштована на PHP API за адресою:

```text
https://testreactwatchshop.zzz.com.ua/api/v1
```

Це значення визначене у `.env.local` (для поточної збірки) та `.env.example` (як шаблон). Якщо адресу бекенду буде змінено, задайте нове значення `VITE_API_BASE_URL` перед виконанням production build.

Після `npm run build` на хостинг потрібно завантажувати **вміст** папки `dist`, а не весь React-проєкт. У production-версії вже вимкнено mock-джерело даних (`VITE_DATA_SOURCE=api`).

Інтегровані операції:

- каталог, бренди, деталі товару та зображення;
- реєстрація, логін, відновлення сесії, профіль та пароль;
- створення і перегляд замовлень;
- admin CRUD товарів, брендів, замовлень, заявок і списку користувачів.

Бекенд має бути доступний через HTTPS та містити актуальний `config.php` з правильними налаштуваннями БД. Його CORS-конфігурація вже дозволяє запити з фронтенду.
