СТОРІНКИ

Головна ( / )
- Просто візуал (тобто мінімум інформації яка б мала бути пов'язана з backend), більше 
інформації про компанію, бренди з якими співпрацюємо та інша інформація
- Декілька карточок товару (Компоненти товару), на які можна буде натиснути та перейти 
до сторінки перегляду всіх характеристик товару
- Header та footer будуть повторюватися на всіх інших сторінках, тому їх засунути в компонент

Сторінка about us
- Просто якась інформація, яка відповідає назві сторінки
- Header та footer

Каталог ( /products )
- Каталог всіх товарів, які є на backend. Відображаються за допомогою компонента картки товару,
який використовувася на основній сторінці
- Фільтри, по яким можна сортувати товари
- Пагінація (по 4 в ряд, 12 на сторінку)
- Header та footer

Сторінка продукту ( /products/:id )
- Відображення сторінки певного товару із всією інформацією
 - Фото товару (Головне + другорядні)
 - Назва
 - Бренд
 - Ціна
 - Гендер
 - Механізм
 - Скло
 - Матеріал ременю
 - Стійкість до води
 - Кількість на складі
 - Опис
- Кількість товару до покупки (можна зменшувати чи збільшувати)
- Кнопка додати до кошика, після якої відображається компонент, який інформує користувача, 
чи додався товар до кошику чи ні.
  - Якщо успішно, то інформує про це, та пропонує перейти до кошику, або перейти до каталогу.
  - Якщо не успішно, то інформує щось типу "Ой, щось пішло не так" та пропонує спробувати ще 
    раз пізніше
- Також міняється сама іконка кошика, якщо товар вже є в кошику.
- Header та footer

Сторінка кошику ( /cart )
- Спеціальні картки товару для кошику 
- Кнопка продовжити покупку (Підтвердити покупку)
 - Якщо користувач не залогінений, то буде відображатися замість тексту на кнопці 
  "продовжити покупку" - "щоб продовжити оформлення покупки, спочатку потрібно увійти в свій 
  аккаунт". Ця кнопка буде перекидати на сторінку входу. Після входу кошик зберігається.
 - Якщо користувач залогінений, то кнопка продовжити покупку після її натиску викликає сторінку 
  (компонент), який інформує користувача про успішне оформлення замовлення, 
  та про те, що менеджер потім зв'яжеться з Вами.
- Якщо до кошику нічого не було додано, то відображається тільки повідомлення що в 
кошику нічого немає, та повідомлення в стилі зробіть свою першу покупку, додавши до кошика товар
- Header та footer

Сторінка входу в аккаунт користувача ( /login )
- Форма для заповнення даних для входу в аккаунт
  - Пошта
  - Пароль
 - Після успішного входу перекидає на сторінку користувача. У Header змінюється назва профілю.
 - Валідація
- Header та footer

Сторінка реєстрації аккаунта користувача ( /register )
- Форма для заповнення даних для входу в аккаунт
  - Ім'я
  - Пошта
  - Пароль
  - Підтвердження паролю
 - Після успішної реєстрації перекидає на сторінку користувача. У Header змінюється назва профілю.
 - Валідація
- Header та footer

Сторінка корисутвача ( /account )
- Якщо користувач не залогінений, то його з цієї сторінки викидає на сторінку входу
- Відображення всієї інформації користувача
 - Ім'я
 - Пошта
 - Номер телефону
- Кнопка змінити дані (перекидає на сторінку зміни даних) 
- Кнопка змінити пароль (перекидає на сторінку зміни паролю) 
- Кнопка виходу з аккаунту
- Header та footer

Сторінка зміни даних | паролю ( /account/edit | /account/edit/password )
- Дві різні сторінки
- Якщо користувач не залогінений, то його з цієї сторінки викидає на сторінку входу
- Форми для змінення даних
 - Ім'я
 - Пошта
 - Номер телефону
 АБО
 - Старий пароль
 - Новий пароль
 - Підтвердження нового паролю
- Валідація
- Header та footer

СТОРІНКИ

Сторінка входу для адміністратора ( /admin/login )
- Візуально відрізняється від логіну звичайних користувачів (більш строгий дизайн)
- Форма для заповнення даних:
 - Пошта
 - Пароль
- Після успішного входу перекидає на Головну сторінку адмінки (Дашборд).
- Валідація та повідомлення про помилку (якщо дані невірні).

Головна сторінка / Дашборд ( /admin )
- Загальна статистика магазину (просто кілька карток з цифрами для краси та наочності):
- Загальна кількість товарів
- Кількість нових замовлень
- Загальна кількість зареєстрованих клієнтів
- Останні 5 замовлень (міні-таблиця для швидкого доступу).
- Sidebar та Header (повторюються на всіх сторінках адмінки).
- Управління товарами — Каталог ( /admin/products )
- Таблиця зі списком всіх годинників:
 - ID, Фото (мініатюра), Назва, Бренд, Ціна, Залишок на складі.
- Кнопка "Додати новий товар" (перекидає на сторінку створення).
- Кнопки дій в кожному рядку таблиці:
 - Редагувати (іконка олівця)
 - Видалити (іконка кошика) -> при натисканні вилазить вікно підтвердження "Ви впевнені?".
- Пагінація (поділ на сторінки).
- Sidebar та Header.

Сторінка створення/редагування товару ( /admin/products/create | /admin/products/edit/:id )
- Форма з усіма характеристиками годинника:
 - Назва (Текст)
 - Бренд (Випадаючий список - Select, який тягне дані з таблиці brands)
 - Ціна (Число)
 - Гендер (Select)
 - Механізм (Текст або Select)
 - Скло (Текст або Select) 
 - Матеріал ременю (Текст)
 - Стійкість до води (Текст)
 - Кількість на складі (Число)
 - Опис (Велике текстове поле - Textarea)
- Блок управління фотографіями:
 - Можливість завантажити нові фото.
 - Відображення вже завантажених фото з кнопкою "Видалити" біля кожного.
 - Вибір "Головного фото" (радіокнопка).
- Кнопка "Зберегти". Після успішного збереження перекидає назад до таблиці товарів.
- Sidebar та Header.

Управління брендами ( /admin/brands )
- Таблиця зі списком брендів (ID, Назва).
- Форма для швидкого додавання нового бренду (просто поле "Назва" і кнопка "Додати", можна 
  зробити над таблицею).
- Кнопки дій біля кожного бренду:
 - Редагувати (змінює назву прямо в рядку або у спливаючому вікні).
 - Видалити.
- Sidebar та Header.

Управління замовленнями ( /admin/orders )
- Таблиця всіх замовлень магазину:
 - ID замовлення, Дата, Клієнт (Ім'я або ID), Загальна сума, Статус.
- Фільтр за статусом (наприклад, показати тільки "Нові").
- Кнопка дій:
 - "Детальніше" (перекидає на сторінку конкретного замовлення).
- Sidebar та Header.

Сторінка деталей замовлення ( /admin/orders/:id )
- Інформація про клієнта та дату замовлення.
- Таблиця куплених товарів (Фото, Назва, Кількість, Ціна на момент покупки, Сума за позицію).
- Блок зміни статусу:
 - Випадаючий список зі статусами (Нове, В обробці, Відправлено, Виконано, Скасовано).
- Кнопка "Оновити статус".
- Загальна сума до оплати.
- Sidebar та Header.

Перегляд клієнтів ( /admin/users )
- Таблиця зареєстрованих користувачів:
 - ID, Ім'я, Пошта, Дата реєстрації.
(Без кнопок редагування/видалення, лише для перегляду інформації).
- Sidebar та Header.

КОМПОНЕНТИ (тільки для адмінки)

Admin Sidebar
- Бокове меню навігації з посиланнями (Дашборд, Товари, Бренди, Замовлення, Клієнти).
- Кнопка "Вийти з акаунту" внизу.

Admin Header
- Верхня плашка, де просто написано "Панель адміністратора" або ім'я поточного адміна.

Confirm Modal (Модальне вікно підтвердження)
- Спливаюче вікно, яке перепитує "Ви дійсно хочете видалити цей елемент?". Використовується 
   при видаленні товарів або брендів, щоб випадковий клік не знищив дані.

Admin Table
- Перевикористовуваний компонент таблиці, щоб не писати дизайн таблиці з нуля для товарів, 
  брендів, замовлень і юзерів.
