# Магазин наручних годинників

Вебзастосунок для магазину наручних годинників із каталогом продукції та макетами для формування замовлень.

**Поточний результат:** Створено багатосторінковий SPA-застосунок із повноцінною клієнтською маршрутизацією (React Router), вкладеними маршрутами та динамічними URL-параметрами (Л 2.2). Інтерфейс базується на чіткій компонентній архітектурі (Л 1.2) з підтримкою глобального стану через Context API та синхронізацією фільтрів з адресним рядком (Л 2.1). Реалізовано асинхронний сервісний шар (Л 3.2), який повністю відокремлює доступ до даних від UI-компонентів: операції створення, перегляду, редагування та видалення замовлень працюють через універсальний контракт із підтримкою локального mock-сервісу (localStorage), імітацією мережевих затримок і захистом від застарілих відповідей. Також підготовлено REST API адаптер (fetch) для майбутнього підключення зовнішнього бекенду через змінні середовища .env. Проведено редизайн UI-елементів, додано стани завантаження, обробку помилок та блокування форм під час збереження.

## Середовище

- **Node.js:** v24.21.0
- **npm:** 11.19.0
- **Git:** 2.45.2.windows.1
- **Docker і Docker Compose:** 27.2.0
- **Основний варіант середовища:** Windows із підтримкою контейнеризації Docker.

## Запуск

### Нативно:

1. Встановіть залежності: `npm install`.
2. Запустіть сервер розробки: `npm run dev`.

### У середовищі Docker:

1. Зберіть образ: `docker compose build`.
2. Установіть залежності в контейнері: `docker compose run --rm web npm install`.
3. Запустіть контейнер: `docker compose up`.
4. Адреса для перегляду в браузері: `http://localhost:5173`.

**Зупинення й видалення контейнера:**

- Зупинити: `docker compose stop`.
- Видалити: `docker compose down`.

## Збірка

- Нативно: `npm run build`.
- У Docker: `docker compose run --rm web npm run build`.
