# ChronoClassic — Магазин наручних годинників

Сучасний повнофункціональний вебзастосунок інтернет-магазину преміальних наручних годинників із клієнтською вітриною, особистим кабінетом покупця, модулем адміністрування та сервісним REST API.

---

## Поточний стан проєкту (Підготовка до курсової роботи)

Проєкт розроблено в межах **підготовки до курсової роботи** та охоплює повний цикл веб-розробки — від компонентної архітектури та маршрутизації до сервісного шару, системи адміністрування та автоматизованого тестування.

### Реалізований функціонал:

1. **Клієнтська частина (Вітрина та магазин):**
   - **Головна сторінка:** Презентаційний блок, вітрина популярних моделей та переваги магазину.
   - **Каталог продукції:** Багаторівнева фільтрація (за брендами, типом механізму, водозахистом, ціною) із синхронізацією стану у рядку запиту URL (`useSearchParams`).
   - **Картка товару:** Детальний перегляд характеристик, галерея зображень та перевірка наявності на складі.
   - **Кошик та замовлення:** Додавання товарів, динамічний підрахунок вартості, можливість додавання коментаря/побажання до замовлення та збереження заявки.
   - **Зворотний зв'язок:** Сторінка «Про нас» із формою подання звернення клієнта.
   - **Автентифікація та профіль:** Реєстрація, авторизація, захищені маршрути (`ProtectedRoute`), особистий кабінет клієнта з історією замовлень та окремими сторінками для зміни персональних даних і безпечної зміни пароля.
   - **UI / UX:** Ексклюзивний дизайн у стилі смарагдово-золотого годинникового бутика (`src/chrono-theme.css`), плавна адаптивність під мобільні пристрої (включно з розширеннями < 400px), автоматичний скрол сторінки вгору при навігації (`ScrollToTop`).

2. **Адміністративна панель (`/admin`):**
   - Окрема авторизація для адміністраторів магазину.
   - **Дашборд:** Зведена статистика замовлень, товарів, клієнтів та фінансових показників.
   - **Керування товарами:** Створення нових товарів із вибірковим списком механізмів, валідацією водозахисту (тільки цифри), обов'язковістю всіх полів (крім опису) та завантаженням декількох фотографій; редагування товарів із прев'ю та керуванням галереєю.
   - **Керування брендами та користувачами:** Повний контроль категорій та бази клієнтів.
   - **Керування замовленнями:** Перегляд замовлень, деталей клієнта та зміна статусів («Нове», «В обробці», «Відправлено», «Виконано», «Скасовано»).
   - **Журнал повідомлень:** Перегляд вхідних звернень користувачів зі сторінки «Про нас» та переведення їх у статус «Опрацьовано».

3. **Архітектура даних та сервісний шар:**
   - Повне відокремлення інтерфейсу від шару збереження даних через єдині контракти.
   - Підтримка автономного локального режиму (`localStorage` з імітацією затримок мережі) та перемикання на реальний REST API за допомогою змінної середовища `VITE_DATA_SOURCE`.
   - Розроблено backend-модуль на PHP та реляційну базу даних MySQL.

4. **Тестування та якість коду:**
   - Застосунок покрито набором із **31 автоматизованого тесту** на базі Vitest та React Testing Library (модульні тести предметної валідації, селекторів замовлень, контракту API, форми кошика та інтеграційні тести маршрутизації).
   - Успішна виробнича збірка без помилок компіляції чи лінтингу.

## Стек технологій

- **Frontend:**
  - React 19, React Router (v8.4)
  - Vite (швидка збірка та HMR)
  - Чистий CSS (Custom Properties, без важких CSS-фреймворків)
  - Lucide React (іконки)
- **Backend & Database:**
  - PHP 8.x (REST API)
  - MySQL
- **Тестування:**
  - Vitest, @testing-library/react, @testing-library/jest-dom, jsdom
- **DevOps:**
  - Docker, Docker Compose, Git

## Встановлення та запуск

### 1. Клієнтська частина (Frontend)

#### Локально:

```bash
# Встановлення залежностей
npm install

# Запуск dev-сервера (http://localhost:5173)
npm run dev

# Запуск автоматизованих тестів
npm test

# Оптимізована виробнича збірка
npm run build
```

#### Запуск у Docker:

```bash
# Збірка образу
docker compose build

# Встановлення пакетів у контейнері
docker compose run --rm web npm install

# Запуск контейнера
docker compose up
```

### 2. Серверна частина (Backend)

Детальні інструкції щодо розгортання бази даних, конфігурації та тестування через Postman наведено у файлі [backend/docs/setup-and-postman.md](backend/docs/setup-and-postman.md).
